## Собственный проект

**Тема проекта:** игры  
**Главный класс:** Game

**Почему этот объект нужен программе:** хранит основные характеристики компьютерной игры и управляет её состоянием.

**Какие данные хранит объект:**
* название (Name)
* жанр (Genre)
* дата выхода (Releasedate)
* рейтинг (rating)

**Какие значения задаются через конструктор:**
* название
* жанр
* дата релиза

**Какие значения можно задавать автоматически:**
* рейтинг

### Практическая работа №2 (самостоятельный шаг)
* **Добавленное действие:** метод UpdateRating для изменения рейтинга игры.
* **Что получает параметр:** новое дробное значение рейтинга (double newRating).
* **Проверенный отказ и значения:** отклонена попытка установить рейтинг вне диапазона 0.0–10.0 (15.0); начальный рейтинг 9.3 изменился на 9.8 после допустимого вызова и остался 9.8 после недопустимого.
